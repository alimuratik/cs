# Техническое задание: Редизайн бейджей и витрины ачивок Зала Славы

## 🎯 Цель задачи
Внедрить согласованный соревновательный редизайн бейджей и витрины ачивок Зала Славы в файлах `templates/achievements.html` и `site/css/style.css`, провести валидацию и задеплоить изменения на GitHub Pages.

---

## 📋 Требования к реализации

### 1. Убрать цифры и индексы из названий рангов (никаких 1, 2, 3 и I, II, III)
- Полностью исключить путающие цифры и римские обозначения во всех бейджах, карточках и подсказках.
- Использовать только чистые, благородные названия металлов:
  - 🥇 **Золото** (+500 PTS)
  - 🥈 **Серебро** (+250 PTS)
  - 🥉 **Бронза** (+100 PTS)

### 2. Цветовая иерархия карточек наград (`shelf-medal-card`)
- **🥇 Золото (Единственный сплошной золотой фокус):**
  - **Светлая тема:** Теплый шампань-градиент (`linear-gradient(165deg, #fffdf2 0%, #fef9c3 35%, #fffbeb 100%)`), 24K золотая рамка `2px solid #eab308` с мягкой аурой свечения (`box-shadow: 0 10px 24px -4px rgba(234, 179, 8, 0.32)`), золотая корона `👑 Золото`.
  - **Темная тема:** Глубокий обсидиановый фон с внутренним золотым радиальным свечением (`radial-gradient`), золотистым ореолом в правом верхнем углу и внешней аурой свечения `0 0 35px -5px rgba(245, 158, 11, 0.5)`.
- **🥈 Серебро (Темная стальная рамка):**
  - **Светлая тема:** Морозно-платиновый фон с **выразительной темной стальной рамкой (`2px solid #64748b`)**, чтобы карточка выглядела четко и не путалась с пустыми/заблокированными слотами.
  - **Темная тема:** Графитовый фон со светлой полированной стальной рамкой `2px solid #94a3b8`.
- **🥉 Бронза (Чистый белый фон + аккуратная бронзовая рамочка):**
  - **Светлая тема:** **Чистый нейтральный белый фон (`#ffffff`)** без тяжелой оранжевой заливки, а **рамочка аккуратно закрашена цветом благородной бронзы (`2px solid #a86239`)**.
  - **Темная тема:** Глубокий темный slate-фон (`#131b2e`) с бронзово-медной рамкой `2px solid #c2410c`.
- **🔒 Неоткрытые / Пустые карточки:**
  - Серая пунктирная рамка `1.5px dashed #cbd5e1` (в темной теме `#334155`), полупрозрачность 55–65%.

### 3. Интерактивная полка наград в Таблице Зала Славы (`glory-row`)
- В строке игрока в ячейке наград: компактная кнопка `🎖️ Награды (N) ▼` со счетчиками медалей `🥇 X`, `🥈 Y`, `🥉 Z`.
- Клик по строке плавно раскрывает подстроку `<tr><td colspan="6">...</td></tr>` с витриной карточек игрока (для топ-1 игрока полка открыта по умолчанию).
- В шапке полки: имя игрока, начисленные очки славы и быстрые фильтры: `Все (N)`, `🥇 Золотые`, `🥈 Серебряные`, `🥉 Бронзовые`.

### 4. Адаптивность для мобильных устройств (360–430px)
- В мобильном представлении карточки на полке выстраиваются в 2 колонки (`grid-cols-2`).
- Медальоны пропорционально масштабируются (`54–60px`).
- Текст не сминается и не обрезается, отсутствие горизонтальной полосы прокрутки.

## 🚀 Команды сборки, проверки и деплоя
После внесения изменений выполнить:
```bash
# 1. Перегенерация страниц
python run.py --stage site

# 2. Проверка целостности
python run.py --stage verify

# 3. Фиксация и отправка изменений для публикации на GitHub Pages
git add templates/achievements.html site/css/style.css
git commit -m "feat(achievements): upgrade medal shelf styling with clean gold, silver, bronze hierarchy"
git push origin main
```
