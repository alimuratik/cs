# CS2 Demo Analytics — PROJECT STATE SNAPSHOT
# Обновляется при каждом `python run.py`. Этот файл читается AI-агентами для восстановления контекста.

## ТЕКУЩЕЕ СОСТОЯНИЕ ПРОЕКТА

### Матчи и данные
- Демки в `demos/` сгруппированы по папкам DDMMYYYY
- Матчи: `data/matches/{match_id}.json`
- Реестр: `data/registry.json`
- История игроков: `data/players_db.json`

### Экономическая классификация (Team Equipment Value)
- `Pistol`: раунды 1 и 13
- `Full Eco`: < 5000
- `Semi-Eco`: 5000 – 10000
- `Force Buy` / `Semi-Buy`: 10000 – 20000
- `Full Buy`: > 20000
- `Hero Buy`: 1 игрок >4500, остальные суммарно <3200
- `Anti-Eco`: раунды 2/14 после победы против эко соперника
- ОГРАНИЧЕНИЕ: estimate_team_equipment() оценочная (~85% точность). awpy не даёт реальный баланс.

### MMR и Ранговая система (Faceit 10 Levels & Unranked)
- Старт: 1000 MMR -> Level 6
- Победа/поражение: +-15 pts (zero-sum)
- Личный бонус: +-до 10 pts (HLTV Rating 2.0 с учетом FK и FD)
- Калибровка: первые 5 матчей ПО ХРОНОЛОГИЧЕСКОЙ ДАТЕ (+-25 pts)
  - Игроки на калибровке опущены в нижнюю часть таблицы лидеров под разделитель, ранг `—`.
  - Для калибрующихся отображается бейдж Faceit **Unranked** (серый пунктирный круг со знаком `?`).
  - Значение MMR для калибрующихся и неактивных игроков (`is_inactive`) отображается нейтральным серым цветом (`text-slate-400 font-mono`).
- 10 уровней Faceit с аутентичными SVG-иконками (`site/icons/faceit/level_{0..10}.svg`):
  Lv10: >=1180 | Lv9: 1135-1179 | Lv8: 1090-1134 | Lv7: 1045-1089 | Lv6: 1000-1044
  Lv5: 955-999 | Lv4: 910-954 | Lv3: 865-909 | Lv2: 820-864 | Lv1: <820 | Unranked: калибровка

### Боевая статистика (FD и Clutches)
- **First Deaths (FD)**: строго первый погибший игрок в каждом раунде (1 FK стрелку, 1 FD жертве).
- **Клатчи (1vX)**: отслеживание живых игроков в каждом раунде. Когда игрок остается один против 1+ врагов, начисляется попытка (`clutch_attempts`); при победе команды в раунде — засчитывается выигрыш клатча (`clutch_wins`).

### Ролевая классификация (instruction/role.txt)
- Строгий расчёт на основе реальной статистики оружия и боевых действий:
  - Снайпер (Main AWP): AWP% >= 20%
  - Энтри-фраггер (Entry Fragger): FK% >= 14% или опенинг-дуэли >= 0.15
  - Второй номер (Trader): размены (trades / kills >= 20%)
  - Саппорт (Support): урон гранатами (UD >= 6.0/rnd) или флеш-ассисты (FA >= 0.35/m)
  - Опорник (Anchor): высокий KAST, низкие первые смерти на приёме точек
  - Люркер (Lurker): соло-позиционирование, поздние фраги, низкий ранний контакт
  - Клатчер (Clutcher): высокий винрейт 1vX при наличии попыток
  - Универсал (Flex Rifler): сбалансированная винтовочная игра
- Каждому игроку присваивается **Основная роль** и **Вторая роль** (например, `Снайпер / Энтри-фраггер`).

### Рейтинг по навыкам (skills.html)
- Выделенная страница `site/skills.html` со сравнительными таблицами по всем 10 параметрам:
  Aim, Positioning, Utility, Game Sense, Entry, Trading, Clutch, Discipline, Economy, Overall Impact
- Ссылка «Навыки» интегрирована в главное навигационное меню (`base.html`).
- Шкалы навыков на странице профиля игрока (`player.html`) кликабельны и ведут на соответствующий таб навыка (`skills.html#aim`, `skills.html#utility` и т.д.).

### Steam ID
ВСЕГДА через clean_steamid(val). Никаких float/scientific notation как ключей!

### AI-анализ
- Инструкция: instruction/rounds.txt (9-пунктовый шаблон)
- Модель: gemini-2.5-flash
- Fallback: локальный движок в scripts/ai_analysis.py
- Markdown **bold** конвертируется в HTML через format_round_analysis() в generate_site.py

### Дизайн и айдентика
- **Брендинг KASE**: Векторная 3D пирамида KASE в хедере (`#50aa40`, `#8abc39`, `#1d7334`) в минималистичном стиле без фоновой плашки.

  - Основной акцент: Изумруд (`#10b981`, `emerald-*`)
  - Премиальный / Чемпионский акцент: Золото (`#f59e0b`, `#fbbf24`, `amber-*` / `yellow-*`)
  - Рейтинг 8.0-10.0: Чемпионский золотой градиент (`bg-gradient-to-r from-amber-950 to-yellow-950 text-amber-300 border-amber-400/60`)
  - Рейтинг 7.0-7.9: Изумрудный KASE (`emerald`) — высокий / хороший уровень
  - Рейтинг 5.0-6.9: Спокойный янтарно-желтый (`amber`/`yellow`) — средний уровень
  - Рейтинг 1.0-4.9: Красный (`rose`) — зона риска / ниже базовой нормы 5.0
- Tailwind CSS через CDN (нет purge — все динамические классы работают)
- SVG иконки оружий: https://raw.githubusercontent.com/ChetdeJong/cs2-killfeed-generator/master/public/weapons/{slug}.svg
- Маппинг: _WEAPON_SLUG_MAP в scripts/generate_site.py

### Запуск и этапы конвейера
- `python run.py`                           # Полный цикл
- `python run.py --stage [stage]`           # Модульный запуск конкретного этапа:
  - `parse`  : Поиск и awpy-парсинг новых демок
  - `calc`   : Аналитический расчет рейтингов 1-10, ролей и MMR
  - `ai`     : Анализ матчей через Gemini API
  - `faceit` : Синхронизация официальной статистики с FACEIT API
  - `site`   : Мгновенная перегенерация HTML страниц
  - `verify` : Верификация целостности данных и артефактов
- `python run.py --force`                   # Полная очистка кэша и перепарсинг
- `python -m scripts.verify_integrity`      # Проверка целостности данных

### Официальная интеграция с FACEIT API & Персонализация
- **FACEIT API (`scripts/fetch_faceit.py`)**:
  - Конфигурация: `FACEIT_API_KEY` в `scripts/config.py` (чтение из `.env` / окружения с безопасным fallback).
  - Локальное кэширование в `data/faceit/{clean_steamid}.json` (TTL 24ч для активных, 7д для 404).
  - Метрики: никнейм, уровень (1-10), Elo, Elo delta (`▲/▼`), тренд (`▲ 3W • На подъёме` / `▼ 2L • Спад` / `● Стабильно`), полоса прогресса до след. уровня, K/D, винрейт, матчи, хедшоты, 5 последних игр, сегменты карт.
  - Векторные SVG бейджи: круговая геометрия уровней Faceit (`scripts/faceit_icons.py` -> `site/icons/faceit/level_{0..10}.svg`).
- **Персонализация («👤 Кто ты?»)**:
  - Виджет выбора профиля в шапке сайта (`templates/base.html`) с сохранением в `localStorage`.
  - Клиентская подсветка строк таблицы лидеров и мобильных карточек (`[data-steamid]`) с бейджем `⭐ ВЫ` и изумрудным свечением.
  - На странице игрока (`player.html`): брендированный блок FACEIT CS2 со ссылкой на платформу и историей матчей.

### Известные ограничения
1. estimate_team_equipment() оценочная — игроки без фрагов невидимы
2. Если видишь старые шаблонные фразы — нужен run.py --force
3. Иконки оружий и Tailwind требуют интернет (внешние CDN)
4. Без указания FACEIT_API_KEY блоки Faceit скрываются без поломки верстки.
