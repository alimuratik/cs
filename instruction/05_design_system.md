# Руководство по дизайн-системе: Emerald & Gold Cyber Theme (05_design_system.md)

## 📌 Концепция визуального стиля
Платформа спроектирована в стиле премиальных киберспортивных трансляций (BLAST Premier, ESL Pro League, HLTV Award Show) с глубокой темной темой, неоновыми акцентами, матовым стеклом (Glassmorphism) и контрастной типографикой.

---

## 🎨 1. Цветовая палитра и токены (:root)

```css
:root {
  /* Фоны */
  --bg-main: #07080c;             /* Ультра-глубокий темный фон */
  --bg-surface: #0e1017;          /* Промежуточная подложка */
  --bg-card: rgba(16, 19, 28, 0.85); /* Матовое стекло карточек */
  --bg-card-hover: rgba(24, 28, 42, 0.95);

  /* Фирменные цвета (Emerald & Gold) */
  --color-primary: #10b981;       /* Изумрудный KASE */
  --color-accent: #f59e0b;        /* Теплый янтарь / Золото */
  --color-gold-bright: #fbbf24;   /* Яркое чемпионское золото */
  --color-secondary: #06b6d4;     /* Неоновый циан */

  /* Стороны команд */
  --color-ct: #3b82f6;            /* CT Синий */
  --color-t: #eab308;             /* T Золотой */

  /* Типографика */
  --font-family: 'Inter', sans-serif;
  --font-numbers: 'Rajdhani', sans-serif;
}
```

## 👑 2. Цветовая шкала рейтингов игроков (1.0 — 10.0)

Каждый числовой рейтинг в интерфейсе автоматически окрашивается в соответствии с правилом:

| Диапазон | Класс | Цвет текста | Свечение / Фон | Описание уровня |
|---|---|---|---|---|
| **8.0 — 10.0** | `.rating-gold` | `#fbbf24` (Золото) | `rgba(245, 158, 11, 0.35)` | 👑 Элитный / Чемпионский перформанс |
| **7.0 — 7.9** | `.rating-green` | `#10b981` (Изумруд) | `rgba(16, 185, 129, 0.30)` | 🟢 Высокий / Надежный уровень основы |
| **5.0 — 6.9** | `.rating-yellow`| `#f59e0b` (Янтарь) | Нет | 🟡 Базовый средний уровень игры |
| **1.0 — 4.9** | `.rating-red`   | `#ef4444` (Кармин) | Нет | 🔴 Зона риска / Ниже базового уровня |

## 🔤 3. Шрифтовая иерархия
- **Числовые данные, рейтинги, счета, MMR**: Шрифт **`Rajdhani`** (жирность 600, 700, 800) с увеличенным трекингом. Придает интерфейсу высокотехнологичный киберспортивный вид.
- **Интерфейсные тексты, описания, аналитика**: Шрифт **`Inter`** (жирность 400, 500, 600) с высокой читаемостью на темных фонах.

## 🧩 4. Компоненты интерфейса

### Карточки Glassmorphism (`.glassmorphism`)
- `backdrop-filter: blur(16px)`
- `border: 1px solid rgba(255, 255, 255, 0.08)`
- `border-radius: 16px`
- Плавный `hover` с микро-подъемом (`transform: translateY(-2px)`) и усилением бордера.

### Интерактивные фильтры-таблетки (`.filter-pill`)
- Служат для моментального переключения без перезагрузки страницы (карты, победы/поражения, тиры игроков).
- Активное состояние: изумрудная рамка `border-emerald-500` и фон `bg-emerald-500/20` с мягким неоновым свечением.

### Персонализация пользователя («Кто ты?»)
- При совпадении `steam_id` с сохраненным в `localStorage`:
  - К строке или карточке добавляется класс `.my-profile-highlight`.
  - Левый изумрудный индикатор шириной 4px и мягкий градиентный фон.
  - Бейдж `⭐ ВЫ`.

## 📱 5. Адаптивность и мобильный интерфейс
- **Десктоп (> 1024px)**: Полноценные многоколоночные таблицы со всеми 10 рейтингами, радар-чартами и очными дуэлями.
- **Планшет (768px – 1024px)**: Адаптивные 2-колоночные сетки с горизонтальной прокруткой таблиц.
- **Смартфон (< 768px)**: Автоматическая трансформация таблиц в интерактивные карточки-аккордеоны (`<details>`), оптимизированные под управление одной рукой.
