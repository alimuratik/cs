# Интеграция с официальным FACEIT API v4 (04_faceit.md)

## 📌 Назначение модуля
Модуль `scripts/fetch_faceit.py` обеспечивает официальную синхронизацию профилей игроков с платформой FACEIT. Модуль подтягивает текущий соревновательный Elo, официальный уровень (Level 1–10), пожизненную статистику и историю недавних игр.

---

## 🔑 Конфигурация и API-ключ
1. **Переменная окружения**: `FACEIT_API_KEY` задается в файле `.env` в корне проекта или в GitHub Secrets репозитория.
2. **Безопасный Fallback**: Если ключ не задан, скрипт выводит информационное предупреждение и завершает работу без ошибок (Exit Code 0). Сайт генерируется в штатном режиме, а блоки Faceit для отсутствующих игроков бесшовно скрываются.

---

## 🌐 Используемые эндпоинты FACEIT API v4

Все запросы отправляются с заголовком:
`Authorization: Bearer {FACEIT_API_KEY}`

1. **Поиск профиля по Steam ID (64-бит)**:
   `GET https://open.faceit.com/data/v4/players?game=cs2&game_player_id={clean_steamid}`
   - Возвращает: `player_id`, `nickname`, `avatar`, `games.cs2.skill_level` (1–10), `games.cs2.faceit_elo`, `faceit_url`.

2. **Пожизненная статистика CS2**:
   `GET https://open.faceit.com/data/v4/players/{player_id}/stats/cs2`
   - Возвращает: средний K/D Ratio, Win Rate %, общее число сыгранных матчей, текущий Win/Loss Streak.

3. **История последних 5 матчей**:
   `GET https://open.faceit.com/data/v4/players/{player_id}/history?game=cs2&limit=5`
   - Возвращает: дату матча, название карты, результат (`WIN` / `LOSS`), счет раундов.

## 💾 Политика кэширования (`data/faceit/{clean_steamid}.json`)

Чтобы не превышать лимиты запросов FACEIT API и ускорить сборку сайта, используется локальный кэш:
- **Время жизни успешного кэша (TTL)**: **24 часа**.
- **Кэширование отсутствующих аккаунтов (404 Not Found)**:
  Если у игрока нет аккаунта на FACEIT, создается запись:
  ```json
  {
    "steam_id": "76561198...",
    "found": false,
    "cached_at": "2026-09-14T12:00:00"
  }
  ```
  Срок жизни отрицательного кэша — **7 дней**, что исключает повторные бессмысленные запросы.
- **Принудительное обновление**: Вызов `python run.py --stage faceit --force` игнорирует TTL и обновляет всех игроков.

## 🎨 Векторные SVG бейджи уровней (1–10)
Скрипт `scripts/faceit_icons.py` генерирует пиксель-перфект векторные SVG иконки для каждого уровня в `site/icons/faceit/level_{0..10}.svg`:
- **Level 1–3**: Графит и мягкий оранжевый акцент.
- **Level 4–7**: Насыщенный янтарно-оранжевый со спицами прогресса.
- **Level 8–9**: Глубокий терракотовый оранж.
- **Level 10**: Фирменный рубиново-красный с контрастным белым ободом и ярким свечением.
- **Level 0 (`?`)**: Нейтральный серый бейдж для не калиброванных или не найденных аккаунтов.
