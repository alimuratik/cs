# Математика рейтингов, All-Time MMR и аналитический движок (02_analytics_ratings.md)

## 📌 Назначение модуля
Модуль `scripts/analyze.py` рассчитывает объективные метрики личного мастерства игроков, сквозной соревновательный MMR, тактические архетипы, стабильность и синергию в матчах.

---

## ⚖️ 1. Десятипараметрическая система рейтингов (1.0 — 10.0)

Каждый игрок оценивается по 10 независимым параметрам с линейной интерполяцией между базовым уровнем (5.0) и элитным потолком (10.0) с ограничением `clamp(1.0, 10.0)`:

$$\text{Rating} = \text{clamp}\left(1.0, 10.0, 5.0 + 5.0 \times \frac{\text{Value} - \text{Base}}{\text{Ceiling} - \text{Base}}\right)$$

| Параметр | Ключевые метрики и веса | База (5.0) | Потолок (10.0) |
|---|---|---|---|
| **1. Aim** | HS% (50%), ADR (30%), Kill Efficiency (20%) | HS=40%, ADR=70 | HS=65%, ADR=100 |
| **2. Positioning** | Deaths/Round (40%), Survival% (30%), Traded Deaths% (30%) | DPR=0.75, SR=28% | DPR=0.50, SR=48% |
| **3. Utility** | Utility Dmg/Round (45%), Flash Assists (35%), Grenades/Round (20%) | UD=8, FA=0.8 | UD=22, FA=3.5 |
| **4. Game Sense** | KAST% (45%), Trade Rate (30%), Win-share (25%) | KAST=66%, TR=22% | KAST=80%, TR=45% |
| **5. Entry** | Opening Duel Rate (50%), Entry Win% (50%) | ODR=12%, EW=45% | ODR=26%, EW=65% |
| **6. Trading** | Re-frag% (60%), Скорость размена (40%) | TR=22% | TR=48% |
| **7. Clutch** | Винрейт клатчей (60%), Число попыток (40%) | CWR=20% | CWR=50% |
| **8. Discipline** | Экономическая дисциплина закупов, сохранение оружия | 5.0 | 9.5 |
| **9. Economy** | K/D на эко/форсах (50%), Save-rate (50%) | 5.0 | 9.5 |
| **10. Overall Impact** | Взвешенное среднее всех 9 параметров + HLTV 2.0 | 5.0 | 10.0 |

### Цветовая индикация в интерфейсе (Emerald & Gold)
- `8.0 — 10.0`: 👑 **Элитный / Чемпионский** (`rating-gold`, золото `#fbbf24`, свечение `#f59e0b`)
- `7.0 — 7.9`: 🟢 **Высокий / Надежный** (`rating-green`, изумрудный `#10b981`)
- `5.0 — 6.9`: 🟡 **Базовый / Средний** (`rating-yellow`, янтарь `#f59e0b`)
- `1.0 — 4.9`: 🔴 **Зона риска / Ниже базы** (`rating-red`, кармин `#ef4444`)

## ⚡ 2. Движок соревновательного MMR (All-Time Zero-Sum Engine)

Рейтинг игроков не обнуляется каждый сезон, формируя непрерывную прозрачную соревновательную историю.

### Формула дельты матча:
$$\Delta\text{MMR} = \left( \text{BaseOutcome} + \text{ImpactMod} \right) \times \text{CalibrationMult}$$

1. **Командный исход (BaseOutcome)**:
   - Победа команды: `+15 MMR`
   - Поражение команды: `-15 MMR`
   - Ничья (12:12): `0 MMR`
2. **Личный импакт (ImpactMod, от -8.0 до +8.0)**:
   $$\text{ImpactMod} = \text{clamp}\left(-8.0, +8.0, 8.0 \times \frac{\text{HLTV} - 1.00}{0.60}\right)$$
   - При победе со звездным HLTV 1.60: $+15 + 8 = +23\text{ MMR}$.
   - При поражении со звездным HLTV 1.60: $-15 + 8 = -7\text{ MMR}$ (личный скилл минимизирует потерю!).
   - При поражении со слабым HLTV 0.40: $-15 - 8 = -23\text{ MMR}$.
3. **Калибровка (CalibrationMult)**:
   - Первые 5 сыгранных матчей игрока: множитель `×1.5` (волатильность до $\pm 35$ MMR).
   - Начиная с 6-го матча: множитель `×1.0`.

### Соответствие рангов уровней (Community Levels):
- **1000 MMR** — Стартовая точка всех игроков (Level 6).
- `Level 10`: $\ge 1350\text{ MMR}$ (Грандмастер)
- `Level 9`: $1250 - 1349\text{ MMR}$
- `Level 8`: $1150 - 1249\text{ MMR}$
- `Level 7`: $1050 - 1149\text{ MMR}$
- `Level 6`: $950 - 1049\text{ MMR}$ (Базовый уровень)
- `Level 5`: $850 - 949\text{ MMR}$
- `Level 4`: $750 - 849\text{ MMR}$
- `Level 3`: $650 - 749\text{ MMR}$
- `Level 2`: $550 - 649\text{ MMR}$
- `Level 1`: $< 550\text{ MMR}$

## 🧭 3. 2D Матрица тактического архетипа игрока

Позиционирование каждого игрока на координатной плоскости $[-50, +50] \times [-50, +50]$:
- **Ось X (Агрессия / Пейсинг)**:
  Рассчитывается из частоты опенинг-дуэлей (FK/FD), среднего времени первого контакта и пика.
  - Положительные значения ($> 0$): Агрессивный энтри-фраггер, создатель пространства.
  - Отрицательные значения ($< 0$): Пассивный якорный игрок, опорник, люркер.
- **Ось Y (Влияние на исход / Роль в структуре)**:
  Рассчитывается из HLTV 2.0, винрейта раундов при жизни игрока и ADR.
  - Положительные значения ($> 0$): Звездный керри / Фраг-лидер команды.
  - Отрицательные значения ($< 0$): Системная опора, саппорт, разменщик.

## ⚔️ 4. Очные дуэли 1v1 (Бойцовский клуб / Head-to-Head)
Модуль рассчитывает полную матрицу личных противостояний игроков:
- Кто кого сколько раз убил за все матчи.
- **Немезида (Nemesis)**: Соперник, нанесший игроку больше всего смертей с максимальной отрицательной разницей.
- **Любимая жертва (Favorite Victim)**: Соперник, против которого достигнут максимальный положительный винрейт дуэлей.
